## Which version does this guide describe?

These guides describe the integrated **source preview**, not a promise that every
feature is in an installed or published release. Use the instructions supplied
with an installed release; do not overwrite it to match this guide.
Use Windows, PowerShell and actual Node 24.15+ (24.x LTS) or Node 26+ for the
source dependency requirements. See the [quick start](quick-start.md).
[Source provenance](engineering-reference.md) and
[package version](../package.json) are recorded separately from user instructions.

## Optional background

The guides explain the vision, decisions and workflow without presentation
prerequisites. The [six-slide opening deck](../development/docs/tandem-opening-slides-v2.html#1)
is a short illustration; the [15-slide extended deck](../development/docs/tandem-opening-slides-light.html#1)
adds hidden-expectation examples, a historical tank-game walkthrough and Q&A.
See [historical caveats](the-tandem-story.md#optional-background-and-historical-illustrations)
and [source provenance](../development/docs/README.md#presentation-provenance).
These are explanatory material, not a release or test report. Open checked-out
HTML in a browser; a repository website may display source instead.
