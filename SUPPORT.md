# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/microsoft/Tandem/issues)
to track bugs and feature requests. Please search existing issues before filing
new issues to avoid duplicates. For new issues, file your bug or feature request
as a [new issue](https://github.com/microsoft/Tandem/issues/new).

For help and questions about using Tandem, start with the
[quick start](docs/quick-start.md), [user manual](docs/user-manual.md) and
[troubleshooting guide](docs/troubleshooting.md). If those do not answer your
question, open a GitHub issue describing the problem, source/package version,
operating system and steps to reproduce. Do not include credentials, private
launch URLs or sensitive project content. There is no guaranteed response time.

Report security vulnerabilities through [SECURITY.md](SECURITY.md), not public
GitHub issues. For contribution guidance, see [CONTRIBUTING.md](CONTRIBUTING.md).

## Microsoft Support Policy

Support for Tandem is limited to the resources listed above.
