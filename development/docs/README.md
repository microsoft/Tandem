Discovery and Development remain independently usable. The implemented bridge
freezes reviewed documents/assets/source and a single request envelope; Designer
continues from that evidence in the existing native owner. Finishing Prototype
alone does not invoke it. See [reviewed discovery handoff](../README.md#reviewed-discovery-handoff).

Historical internal presentations, discussion diagrams and integration progress
logs have been removed from the public-facing tree. Their screenshots and
reported runs were not current product qualification. Source provenance remains
in the [Development guide](../README.md#source-provenance); current behavior is
defined by maintained source and tests.
